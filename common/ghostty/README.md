# Ghostty

## Config File Location

| OS    | Path                         |
| ----- | ---------------------------- |
| Linux | `~/.config/ghostty/config`   |
| macOS | `~/.config/ghostty/config`   |

Instead of symlinking, include this file from the config above.
Machine specific settings stay in the local config.

```ini
config-file = ~/dotfiles/common/ghostty/config
```
